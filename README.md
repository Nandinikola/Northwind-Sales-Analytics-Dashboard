# Northwind-Sales-Analytics-Dashboard
Interactive Sales Analytics Dashboard built in Power BI with KPI tracking, trend analysis, and data-driven insights.
## Overview
This project is an interactive Power BI dashboard built using the Northwind dataset.

## Features
- Sales KPI Monitoring
- Monthly Sales Trends
- Country-wise Sales Analysis
- Category-wise Performance
- Top Customers Analysis
- Employee Performance Tracking
- Interactive Slicers and Filters

## Tools Used
- Power BI
- DAX
- Data Modeling
- Data Visualization
